# Resonance, Hill spacing and transit-timing sensitivity (synthetic)

This is a separate numerical-validation layer. The existing NASA Archive products and REBOUND simulations are **not** modified or claimed to be rerun. All examples use seeded synthetic data or explicitly assumed mass priors.

1. **First-order resonant-angle sampling.** For a j:(j-1) pair, the two angles are j lambda_outer − (j−1) lambda_inner − varpi_i/o. Circular resultant length and unwrapped angular span distinguish well-sampled synthetic circulation from small-amplitude libration-like behaviour. The calculation cannot establish resonant capture without sufficiently long, well-sampled, physically constrained integrations. Undefined periapses for circular orbits and time-sampling aliases must be handled by the investigator.
2. **Mutual Hill-spacing mass-prior sensitivity.** With the massless Keplerian approximation a_out/a_in=(P_out/P_in)^(2/3), the code computes spacing in mutual Hill radii and propagates correlated lognormal prior draws for the two planetary masses and an independent stellar-mass prior. The familiar 2 sqrt(3) spacing threshold applies only as an idealized sufficient criterion for two nearly circular, coplanar planets; it is **not** a stability certificate for compact multi-planet systems.
3. **Covariance-aware transit ephemeris and influence.** Generalized least squares fits t_n=t0+Pn using a known positive-definite timing covariance and returns residuals and formal conditional parameter errors. A seeded example injects correlated timing noise and a sinusoidal TTV-like component. Leave-one-epoch-out period shifts and quadratic-versus-linear chi-square difference are descriptive sensitivity checks; the quadratic comparison does not provide a calibrated detection significance. Covariance and TTV parameters are illustrative, not measured.

Reproduce with `python -m pytest tests/test_robustness.py -q` and `python scripts/run_robustness.py` after installing the repository in editable mode. The JSON output is explicitly marked is_observation=false. No new planet, resonance, or transit-timing detection is claimed.
